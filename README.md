# Student Grade Calculator

A simple program that calculates a student's total marks, percentage and final grade based on their subject scores.

## ✨ Features
- Accepts marks for multiple subjects.
- Calculates total marks and percentage.
- Determines the final grade automatically.
- Displays the student's result clearly.

## 🛠️ Technologies Used
- Python

## ▶️ How to Run
1. Clone or download this repository.
2. Open the project in your code editor.
3. Run the Python file.
4. Enter the subject marks to calculate the result.
